# Factora Journal — Homepage Content Plan

## Language and audience

The primary interface language is international English. Positioning is written for readers, researchers and editors in the United States and Europe while remaining globally understandable. The site will not imply that any entity profile has been completed until the editorial files are ready.

## Homepage sequence

| Order | Section | Purpose |
| --- | --- | --- |
| 1 | Research ticker and masthead | Establish the journal identity and current pre-publication status |
| 2 | Asymmetric hero | State the evidence-first publishing promise |
| 3 | Collection index | Present the seven supported entity categories without naming entities |
| 4 | Publication dossier | Explain what happens before any profile is published |
| 5 | Collection readiness | Show editorial progress by category without fabricated profiles or source counts |
| 6 | Evidence standard | Explain source labels, open questions and corrections |
| 7 | Dispatch signup | Offer an editorial update while clearly disclosing static-demo behavior |
| 8 | Policy-rich footer | Link to methodology, legal pages, contact and crawler resources |

## Functional scope

The static site supports responsive navigation, collection filtering, a route search overlay, local newsletter-form feedback, focus states, reduced-motion support and complete crawl files. No database, submitted profile, account system or external API is represented.
